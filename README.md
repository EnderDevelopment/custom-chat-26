# CustomChat26

CustomChat26 is a Minecraft plugin designed for Paper servers, specifically for Minecraft 26.2. It replaces the default chat system with a fully customizable chat experience. Players can type messages normally, and the plugin automatically processes and displays them in a custom format. The plugin supports comprehensive color and formatting codes, ensuring that messages are displayed exactly as intended. It also includes features for automatic chat handling, complete chat color-code support, and configurable message formats.

## Install

1. Download the latest release of CustomChat26 from the [GitHub repository](https://github.com/EnderDevelopment/CustomChat26).
2. Place the downloaded JAR file into the `plugins` folder of your Paper server.
3. Restart or reload your server to enable the plugin.

## Use

1. Players can type messages in the chat as usual. The plugin will automatically process and display them in the custom format.
2. To reload the plugin configuration, use the command `/customchat reload`. This requires the `customchat.admin` permission.
